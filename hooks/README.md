# hooks folder (Natural-Language Guide)

Yahaan custom React hooks rakhe hain.

Current usage:
- use-fetch.js: async action call + loading/error/data handling
- use-controlled-state.jsx: controlled/uncontrolled state helper
- use-is-in-view.jsx: element viewport me hai ya nahi detect karta hai

Tip:
- UI behavior debug karte time hooks ka return object console me inspect karo.
